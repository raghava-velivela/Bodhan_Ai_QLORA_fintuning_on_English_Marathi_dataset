For this project, I fine-tuned the state-of-the-art `bodhan-ai/indic-translate` model for English-to-Marathi Neural Machine Translation using 4-bit QLoRA on a Kaggle T4 GPU. The pipeline involved processing and cleaning 1,500 training samples from the AI4Bharat Samanantar corpus, utilizing 997 samples from the FLORES benchmark for validation, and evaluating the model on a 50-sample conversational subset of the AI4Bharat IN22-Conv test dataset. Finally, I successfully assessed the translation performance using the character and word n-gram matching metric (chrF++), achieving a final overall average score of 48.95.
